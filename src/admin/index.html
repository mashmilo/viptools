Site and ads

Saved to the repo, then the site rebuilds and redeploys. Usually live within a few minutes.

Tools

Turn tools on or off, and change their name, short description or category. Disabled tools are removed from the site, the menu and the sitemap at the next build.

API keys

Keys are stored only as Cloudflare environment variables. This page shows whether each one is set; it never shows the key itself. Add the key in Cloudflare Pages → Settings → Environment variables, then redeploy.

Add a new API: a developer adds the endpoint code in the functions folder and a provider entry in this list. The key is then added in Cloudflare with the secret name shown here.
