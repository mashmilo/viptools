Your token is only used in this page to call api.github.com. It is never saved or sent anywhere else.

      Upload one or many files straight to a GitHub repository from your browser. All files go in a single commit, so your history stays clean. Nothing is installed and no account is created with us.

      How to use GitHub Uploader

      Create a fine-grained personal access token on GitHub with Contents set to read and write for the repository you want. Enter the owner, repository and branch, choose your files, and press Upload. The page shows a link to each file when the commit is complete.

      Why one commit

      Uploading several files as one commit keeps your history readable. Each upload appears once, with one message, rather than a long list of separate commits.
