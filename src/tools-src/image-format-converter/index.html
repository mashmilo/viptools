How to convert an image

Choose a file, pick the output format and adjust quality if you chose JPG or WebP. The converted size appears above the download button. Download the new file and upload it wherever you need it.

Which format should you choose

Use JPG for photos when file size matters, because it compresses photographs well. Use PNG for logos, screenshots and graphics that need sharp edges or transparent backgrounds. Use WebP for websites, because it is usually smaller than both JPG and PNG at similar quality and every modern browser opens it.

Transparency and white backgrounds

JPG does not support transparency. When you convert a transparent PNG to JPG, the tool fills the transparent areas with white so the image looks correct. PNG and WebP keep transparency.

Frequently asked questions

Is quality lost? JPG and WebP are lossy, so a lower quality setting makes smaller files with some detail loss. PNG is lossless. Can I convert HEIC photos? Browsers only open formats they support, so export HEIC photos to JPG on your phone first.
