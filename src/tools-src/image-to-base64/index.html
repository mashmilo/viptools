Image to Base64 Converter

Turn any image into a Base64 text string you can paste into HTML, CSS or JSON. Nothing is uploaded.

Select an image to start.

The Image to Base64 Converter turns a picture into a long text string that starts with data:image. You can paste that string straight into an img tag or CSS background, which means the image travels inside the code itself.

How to use it

Choose an image, then copy the result. Use the data URI version in an HTML img tag as the src value. Tick the raw option if your system only wants the Base64 characters without the prefix, for example in some JSON APIs.

When to use Base64 images

Small icons, logos and placeholder images can load with the page and avoid an extra request, which can help very small graphics load faster. Email templates often need embedded images for the same reason. Developers also store small images inside JSON or configuration files.

When not to use it

Base64 makes data about one third larger than the original file. Large photos become heavy text that slows down HTML and cannot be cached on their own, so keep big photos as normal image files. Base64 is also not encryption. Anyone who copies the string can decode the image.

Frequently asked questions

Is my image uploaded? No. The conversion runs in your browser. Which formats work? JPG, PNG, WebP, GIF and SVG work in most browsers.
