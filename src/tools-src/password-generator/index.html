Password Generator

Create strong, random passwords securely in your browser.

The Password Generator creates random, hard-to-guess passwords using your browser's built-in cryptographic random number generator. You choose the length and the character types, then copy the result with one tap. Nothing is transmitted or stored, so the password exists only on your device.

How to use the Password Generator

Set the length first. Sixteen characters is a good default for most accounts, and longer is better for email and banking. Tick the options you want: uppercase letters, numbers and symbols. Press Generate to create a new password, and press it again for another. The strength line estimates entropy in bits, which measures how many guesses an attacker would need. Press Copy and paste the password directly into a password manager or the sign up form.

Why strong passwords matter

Most account takeovers begin with weak or reused passwords. Attackers run automated tools that try millions of common passwords such as names, dates and keyboard patterns every second. A truly random password of sixteen mixed characters would take far longer than a human lifetime to crack by brute force. Because leaked passwords from one site are tested on others, a unique password for every account limits the damage of any single breach. Random generation removes human predictability, which is the main weakness of passwords people invent themselves.

Best practices

Use a reputable password manager so you do not need to memorise dozens of random strings. Never share passwords by chat or email. Turn on two factor authentication wherever it is offered, because it protects you even if a password leaks. Avoid including personal details such as birthdays or pet names. If a site limits symbols, untick that option and increase the length instead, since length contributes more strength than variety. Change passwords immediately if a service announces a breach, and do not reuse an old password with a small modification.
