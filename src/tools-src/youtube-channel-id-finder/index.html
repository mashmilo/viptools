The YouTube Channel ID Finder turns a channel link, an @handle or a link to any video into the channel's permanent ID. The ID always starts with UC and is 24 characters long.

How to use the YouTube Channel ID Finder

Paste a channel link, an @handle such as @channelname, or the link of any video from the channel. Press Find channel ID. The tool shows the channel name, the ID with a Copy button, a ready-made RSS feed link and public numbers such as subscribers and videos.

Why use it

Many tools, plugins and APIs ask for the channel ID, not the handle. YouTube does not show the ID on the channel page any more, so you need a lookup to get it. The ID never changes, which makes it the safest value to store.
