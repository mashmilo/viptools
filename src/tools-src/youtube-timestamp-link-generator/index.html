The YouTube Timestamp Link Generator builds a link that opens a video at an exact time. Enter the video link and the time, and copy the short link, the full link or the embed URL.

How to use the YouTube Timestamp Link Generator

Paste the video link, then set the hours, minutes and seconds where playback should start. The links update as you type. Press Copy next to the version you need, or press Test the link to check where it starts.

Why use it

Long videos are hard to share when only one part matters. A timestamp link takes the viewer straight to that moment, which helps in lessons, tutorials, comments and blog posts. The tool also converts the time to seconds for you, so there is no mental arithmetic.
