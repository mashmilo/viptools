Color Converter

Convert colors between HEX, RGB and HSL codes. Paste one format and get the others instantly for CSS, design tools and code.

Pick any color and instantly see its HEX, RGB and HSL values, ready for CSS and design tools.

How to use Color Converter

Tap the color box, choose a color, and copy the value you need.

Why use Color Converter

Designers and developers switch between color formats constantly. This saves time when building websites and brand styles.

Example

The color #6366F1 is rgb(99, 102, 241) and roughly hsl(239, 84%, 67%). Use HEX for short CSS declarations, RGB when you need to adjust channels, and HSL when you want to change lightness or saturation while keeping the hue.

Color in accessibility

Converting a color is not enough to check readability. Test text contrast against the background, aiming for at least 4.5:1 for normal body text under WCAG AA.

Frequently asked questions

What is the difference between HEX and RGB?

They describe the same colour. HEX writes the red, green and blue values in base 16, while RGB writes them in base 10.

Why use HSL?

HSL separates hue from lightness and saturation, which makes it easier to create lighter or darker shades of one colour.

Does it check contrast?

This tool converts colour formats. Use a dedicated contrast checker to test readability.
