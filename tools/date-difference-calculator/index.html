Date Difference Calculator

Find the number of days between two dates. Useful for deadlines, countdowns, project planning and time tracking.

Calculate the time between two dates in days, weeks and months.

How to use Date Difference Calculator

Choose a start date and an end date. The difference appears instantly.

Why use Date Difference Calculator

Useful for project deadlines, countdowns, pregnancy and travel planning.

Example

From 1 January to 1 March in a non-leap year is 59 days. Whether you count the start or end day changes the total by one, so check which convention your deadline uses.

Useful for

Calculating notice periods, contract terms, pregnancy or project timelines, and how long until an event.

Frequently asked questions

Does the end date count as a day?

The calculator shows the simple difference between the two dates. Add one if you need both the start and end day included.

Does it account for leap years?

Yes. The date system handles leap years automatically.

Are my dates stored?

No. The calculation runs in your browser.
