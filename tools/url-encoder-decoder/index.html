URL Encoder & Decoder

Encode or decode URLs and query strings with percent-encoding. Turn spaces and special characters into safe URL text. Free and private.

URLs can only contain a limited set of characters. This tool converts spaces and special characters into percent-encoded form and back again.

How to use URL Encoder & Decoder

Paste a URL or query value and press Encode to make it safe, or Decode to make it readable.

Why use URL Encoder & Decoder

Correct encoding prevents broken links, failed API calls and tracking errors. Marketers and developers use it when building campaign links and form requests.

Example

A space becomes %20 and an ampersand becomes %26. Encoding a search term such as "fish & chips" before adding it to a URL stops the ampersand from being read as a parameter separator.

When you need it

Developers encode query parameter values, UTM tags and redirect targets. Decoding helps you read long tracking URLs and check what each parameter really contains.

Frequently asked questions

Should I encode a whole URL or just a value?

Encode individual values, such as a query parameter, rather than the whole URL. Encoding the whole URL also converts the characters that separate its parts.

What does percent-encoding mean?

Each unsafe character is replaced by a % sign followed by its hexadecimal byte value, for example %20 for a space.

Does it store my URLs?

No. Encoding and decoding run in your browser.
